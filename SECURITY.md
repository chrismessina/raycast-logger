# Security Policy

## Supported Versions

Security fixes are released for the latest published version of
`@chrismessina/raycast-logger`.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through
[GitHub Security Advisories](https://github.com/chrismessina/raycast-logger/security/advisories/new).
Do not include secrets, access tokens, or sensitive log output in a public issue.

Please include the affected version, a minimal reproduction using synthetic
credentials, the observed output, and the expected redaction behavior. You can
expect an acknowledgement within seven days.
